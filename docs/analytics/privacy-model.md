# Portal18 — Analytics Privacy & Anonymity Model

> [!IMPORTANT]
> **ZERO VISITOR PII | COARSE GEOLOCATION ONLY | PRIVACY THRESHOLD >= 5 EVENTS**

---

## 1. Diretrizes Fundamentais de Privacidade

1. **Zero Visitor PII**:
   - Painéis de anunciantes nunca contêm e-mails, telefones civis, nomes de usuários, endereços IP ou identificadores biométricos de visitantes.
2. **Threshold Mínimo de Agregação (>= 5)**:
   - Termos de busca e dados demográficos regionais são exibidos somente quando atingem no mínimo 5 ocorrências agregadas, impedindo a reidentificação de usuários individuais.
3. **Localização Coarse**:
   - Exibição de alcance regional restrita a Cidade e Estado.
   - Zero persistência ou compartilhamento de coordenadas GPS precisas de visitantes.
4. **Isolamento de Dados Sensíveis**:
   - Dados de Age Assurance, KYC e Sanções nunca trafegam para o pipeline de analytics comercial.
