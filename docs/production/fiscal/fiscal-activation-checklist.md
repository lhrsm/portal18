## 1. 21-Step Fiscal Activation Checklist

1. [ ] **Corporate Entity Ratified**: Formal legal name and trade name registered.
2. [ ] **CNPJ Confirmed**: Valid corporate CNPJ issued by Receita Federal.
3. [ ] **Municipal Registration Confirmed**: Inscrição Municipal active in issuing city.
4. [ ] **Accountant Sign-Off**: Written authorization from certified accounting officer.
5. [ ] **Tax Regime Formally Selected**: Simples Nacional, Lucro Presumido, or Lucro Real confirmed.
6. [ ] **CNAE Codes Selected**: Primary and secondary CNAEs established.
7. [ ] **Municipal Service Codes Configured**: Item LC 116 confirmed with municipal authority.
8. [ ] **ISS Tax Rates Configured**: Versioned tax rate matrix entered in backend settings.
9. [ ] **Withholding Rules Established**: ISS/PIS/COFINS withholding logic confirmed.
10. [ ] **Fiscal Provider Selected**: Third-party aggregator or direct integration chosen.
11. [ ] **Commercial Agreement Signed**: Vendor contract executed if aggregator used.
12. [ ] **Digital Certificate A1 Injected**: Valid certificate uploaded to server vault.
13. [ ] **Sandbox Homologation Passed**: 100% test invoices authorized in municipal sandbox.
14. [ ] **Cancellation Flow Tested**: Document cancellation test verified in sandbox.
15. [ ] **Reconciliation Polling Tested**: Document status lookup verified.
16. [ ] **Customer Data Minimization Verified**: Only statutory required fields collected.
17. [ ] **Accounting Export Validated**: Monthly CSV ledger approved by accountant.
18. [ ] **Backup & Audit Ledger Verified**: Daily database snapshots confirmed.
19. [ ] **Monitoring & Backlog Alerts Active**: Issuance error rate alerts configured.
20. [ ] **Legal & Regulatory Approval**: Final sign-off from Legal Counsel.
21. [ ] **Four-Eyes Kill Switch Removal**: Executive and FinOps dual approval to deactivate `PORTAL18_FISCAL_KILL_SWITCH`.
